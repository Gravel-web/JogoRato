# Rato em busca do queijo

Jogo simples feito em Pygame: mova o rato com as setas do teclado e pegue os
queijos. A cada colisão, o queijo reaparece em uma posição aleatória.

## Como executar

No terminal, dentro desta pasta:

```powershell
python -m pip install -r requirements.txt
python rato_queijo.py
```

## Sprites
